# 自部署与云端能力接入

## 本地基础应用

浏览器 → 同源本地后端 → 本地 SQLite／用户所选模型服务。

- `npm run dev` 同时启动 Vite 网页（9002）和本地 API（4579），网页代理 `/api`。
- `npm run build && npm start` 由同一个服务端口提供网页与 API。
- 首次启动打印随机密码；也可设置 `SKOOB_LOCAL_PASSWORD`。这是单个所有者的工作室，同一实例的登录者共享作品。对公网部署请自行配置 HTTPS 和访问控制。
- 数据默认保存在 `data/`。Key 通过本地生成的 `secrets.key` 加密；该文件与数据库必须一同备份，网页读取配置不会取得完整 Key。
- 支持 OpenAI 兼容 Chat Completions / Responses。使用显式选中的服务商和模型；请求失败不会偷偷切换供应商。自有服务商自行结算，官方中转站由 sub2api 结算。
- 普通会话、UTF-8 文本附件、基础六步创作、章节修改／导出、剧场自建群和文字影游在本地运行。影游 JSON／HTML 保留条件分支；Ink 导出仅支持无变量的分支。
- 模型生成质量、上下文上限、速率与费用取决于所选服务商。每章六师可能产生多次模型请求；逐步确认模式默认开启，停止后保留已完成的环节。

## 四大引擎

浏览器 → 本地后端的固定引擎路由 → 官方云端服务（鉴权与计费）→ 引擎结果。

在页面顶部「连接官方平台」选择授权登录：本地生成随机校验值 → 打开官方 `/site/connect` → 通过现有中转站 OAuth 登录 → 用户明确授权 → 一次性连接码回到发起实例 → 本地后端证明校验值并换取凭证。官方 OAuth client secret 不进入公开项目，访问 Token 不出现在回跳 URL。连接码一分钟有效、只能使用一次；未自动回传时可手动粘贴连接码。

也可手动填写官方支持的 API Key / 登录 Token，保存前调用官方身份校验，用户 ID 从验证结果取得。普通模型 Key 如果不被平台身份接口接受，将明确拒绝；不会因 Key 非空就显示授权成功。中转站模型用量和四大引擎权益分别按现有平台协议处理。

连接后可以查看实际账号、套餐、权益和云端模板目录。断开连接立即停止云端调用，本地作品保留；更换云端地址必须重新验证凭证。服务端仍支持 `SKOOB_CLOUD_URL`、`SKOOB_CLOUD_API_KEY`、`SKOOB_CLOUD_USER_ID`，页面断开操作也会覆盖环境变量提供的连接。

官方端须配套部署 `/site/connect` 及 `/api/v1/account/self-hosted/authorize`、`exchange` 两个交接接口；它们复用现有的 OAuth 一次性交接存储，不新增账户或计费体系。连接方式不等于所有商户 API 已正式开放。

转发范围为 `/api/v1/tianmo`、`tianwang`、`tianwang-library`、`tianyan`、`deai`、`deconstructions`、`covers`、`cover-studio`。任务创建、查询、事件、暂停及恢复使用同一云端源和云端任务 ID，本地不伪造云端执行状态；本地的书、会话与模型 Key 不会整库上传。触发云端操作时，该次操作所需的文本／文件会随请求送往官方服务。

没有云端配置时返回 `CLOUD_NOT_CONFIGURED`，基础功能继续可用。管理接口被拒绝；本地访问密码、登录令牌和 Cookie 不转发给云端。后端不接受客户端传入的任意目标 URL，固定使用部署者配置的服务源，禁止 HTTP 重定向。

当前保留的是官方产品连接适配，并非宣称七项商户 API 已全部正式交付。正式接入版本、授权与价格以开通资料为准。本地快速创作不执行天衍仿真；需要完整仿真创作时使用已开通的官方服务，不能将云端文件路径作为本地结果读取。影游节点配图也需要天工服务，不附带本地生图引擎。

本仓库不包含四大引擎实现、平台提示词库、会员管理、sub2api 管理或生产密钥。商业源码授权、官方引擎服务、模型用量分别约定。


## 模板上传与云端资产

连接面板列出本地智能体模板和技能。用户逐份点击上传，后端以已验证的云端账号调用现有模板/技能接口，再查询云端资产目录确认 `assetId` 与归属；未确认入库返回失败，不把本地保存当作上传完成。重复上传使用按云端源、账号、类型和本地 ID 生成的稳定标识；不会覆盖其他账号或平台内置的同名模板。

上传先保存为自己的云端资产。公开分享通过单独的「提交公开审核」操作复用云端发布接口，遵循既有审核规则。当前上传支持智能体模板和技能正文，不宣称能把完整拆书图谱包、整个本地数据库或所有附件自动同步到云端。
