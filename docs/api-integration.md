# 网页 API 接入边界

所有业务请求均通过 `src/lib/api-origin.ts` 拼接同一个服务源，默认 `https://skoob.cc`。

| 浏览器模块 | 职责 |
| --- | --- |
| `src/lib/account.ts` | OAuth challenge / 一次性交接、账户、权益、跳转中转站 |
| `src/lib/auth-storage.ts` | 当前用户身份；禁止写入平台共享密钥 |
| `src/lib/api.ts` | 作品、模型目录、用户设置、创作、拆书、热点等浏览器请求 |
| `src/lib/general-agent-api.ts` | 会话、附件、任务、取消与携带用户凭证的 SSE |
| `src/lib/general-agent-contracts.ts` | 请求、事件及结果结构校验，不包含引擎执行代码 |
| `src/lib/cover-api.ts` | 用户封面任务与结果 |

## 请求链

网页 → Skoob 服务（验证用户、资源权限、功能权益）→ 私有引擎 → 用户所选模型服务。选择官方中转站时由 sub2api 按所选 Key 与模型计量 Token、结算费用；选择自定义服务时由对应服务商结算，Skoob 不重复计费。

网页只呈现状态和结果，不能决定服务端是否收费。隐藏按钮、修改网页代码、改写用户 ID 均不能替代服务端授权。失败、取消和重试的模型费用以所选服务商的实际记录为准。

## 接入条件

1. HTTPS 页面；登记准确的页面 Origin 与 OAuth returnTo 来源。
2. CORS 允许该 Origin、凭证和实际使用的请求头；不能使用携带凭证的通配 Origin。
3. 保持官方 OAuth challenge 与一次性交接逻辑；不要从 URL 接收登录 Token。
4. 业务请求同时携带当前用户凭证，SSE 采用 fetch 流以传递请求头；切换账号后废弃旧请求。
5. 由服务端验证作品、会话、附件和任务归属；浏览器协议不是第三方商户授权契约。

管理 API、提示词正文、运行时密钥和内部存储不属于本模板。此仓库不提供通用转发代理，不在浏览器持有平台或商户共享 Key。

当前版本完成的是网页与私有实现的源码隔离。第三方域名实际登录、端到端生成和线上扣费需要在官方登记并验收后使用；本次整理没有自动修改官方 CORS、计费配置或部署生产。
