# 焚诀 Skoob · Open-Skoob

**AI 网文创作工作室 —— 让每一个灵感都能长成一本书**

[体验官网](https://skoob.cc) · [快速开始](#快速开始) · [能力总览](#能力总览) · [API 接入](docs/api-integration.md) · [交流与联系](#交流与联系)

Skoob 面向长篇与连载小说创作，连接灵感、大纲、角色、正文与修订，帮助作者推进故事、分析作品和打磨表达。

**Open-Skoob 是可二次开发的网页前端模板**，基于当前 Skoob 网页界面整理。你可以在许可证允许的范围内修改页面、主题与交互，接入官方服务，也可以在模型设置中配置自己的模型服务商。

本仓库只包含一套 React 网页、浏览器接口协议和静态资源。核心创作与分析引擎运行在 Skoob 官方服务端，不随本仓库发布；仅部署网页不能离线运行这些能力。

## 能力总览

以下是网页提供的功能入口，实际运行依赖官方 API、账号权限和所选模型服务。

| 功能 | 用途 |
| --- | --- |
| 创作工作台 | 从灵感、设定和大纲推进到章节写作与修订，管理作品与创作上下文 |
| 智能体与对话 | 通过对话推进创作，配置个人智能体，查看任务进度和结果 |
| 天王拆书 | 分析作品结构、角色与叙事，查看拆书结果和图谱 |
| 天衍世界模拟 | 推演角色互动与剧情走向，为创作提供参考 |
| 天魔热点与扫榜 | 从热点和榜单中寻找选题、故事方向与灵感 |
| 天工 AI 检测与改写 | 辅助检查文本风格、识别 AI 味并调整表达；检测结果仅供参考 |
| 封面与文库 | 管理封面任务、作品和阅读入口 |

## 网页与服务端的边界

```text
可定制的网页
    → Skoob 官方 API（登录、用户数据与任务权限）
        → 服务端核心引擎
            → 用户选择的模型服务：官方中转站 / 自定义服务商
```

| 本仓库包含 | 由官方服务端提供，不包含源码 |
| --- | --- |
| 页面、组件、样式、静态资源 | 核心引擎与任务执行实现 |
| 浏览器请求封装、事件与结果类型 | 平台提示词、内部策略与管理端 |
| 自定义模型与服务商配置界面 | 数据库、服务端密钥与运行配置 |

当前发布范围是网页，不包含本地后端、桌面客户端或手机客户端，也不需要在本地部署数据库。

## 快速开始

环境要求：**Node.js 22 或更高版本、npm**。

```sh
git clone https://github.com/OmMaBaMiHong/open-skoob.git
cd open-skoob
npm ci
npm run dev
```

打开 `http://127.0.0.1:9002`。默认 API 地址为 `https://skoob.cc`。页面能启动不代表登录和业务请求已经获准：本地开发来源及第三方部署域名均需在官方服务登记 CORS Origin 和 OAuth 回跳地址，接入请联系下方邮箱。

构建及预览：

```sh
npm run build
# 停止开发服务器后再启动预览，两者默认使用相同端口。
npm run preview
```

构建输出在 `dist/`，可部署到静态托管服务。部署时请启用 HTTPS，并将前端页面路由回退到 `index.html`，以支持直接访问工作台等子页面。

### API 地址配置

```sh
cp .env.example .env.local
```

`.env.local` 中的 `VITE_API_BASE_URL` 指定 API 源地址，默认值为 `https://skoob.cc`；更改后需重新构建。该设置只改变请求目标，不会启动本地引擎，也不能代替服务端域名授权。

`VITE_*` 变量会公开给浏览器，不能放入平台共享 API Key、商户密钥或 OAuth client secret。用户自己的模型凭证通过模型设置管理。

## 模型选择与费用

保留自定义模型和服务商配置，按自己的需要选择：

| 选择 | 模型 Token 费用由谁结算 |
| --- | --- |
| 官方中转站 | 沿用官方 sub2api 计量与结算，按所选模型和 Key 使用 |
| 自定义模型服务商 / 自有 Key | 由用户与该服务商结算，Skoob 不另收这部分模型 Token 费用 |

模型费用与官方核心服务的使用权限分别管理。配置自己的模型不会让核心引擎在本地运行；网页源码许可也不附带免费 API、模型额度或托管服务权益。服务可用范围与使用说明以 [官网](https://skoob.cc) 为准。

## 第三方部署与 API 接入

当前网页沿用官方 OAuth 用户登录协议，用户登录后访问自己的数据。第三方域名需要登记准确的 CORS Origin 和 OAuth 回跳来源；未经登记，页面可以加载，但登录或跨域请求可能被拒绝。

本仓库提供现有网页的接口封装，不代表独立商户 API Key、公开 SDK 或完整第三方开放平台已交付。接口模块、请求链和接入条件见 [API 接入说明](docs/api-integration.md)。

## 目录与二次开发

```text
src/
  pages/        页面与业务入口
  components/   可复用界面组件
  hooks/        React hooks
  lib/          浏览器 API、登录与协议类型
  styles/       样式
  i18n/         文案与语言配置
public/         静态资源
docs/           API 接入说明
```

修改页面与交互可从 `src/pages/`、`src/components/` 开始；API 源地址统一由 `src/lib/api-origin.ts` 处理。保留用户授权、账号切换和流式请求逻辑，修改后运行 `npm run build` 检查类型与构建。

欢迎通过 [Issues](https://github.com/OmMaBaMiHong/open-skoob/issues) 反馈问题，或提交 Pull Request 改进网页。反馈时请附复现步骤和环境信息，不要上传模型 Key、登录凭证或未授权的作品内容。
