# Skoob Web

可二次开发的 Skoob 网页模板，基于当前网页界面整理。可修改页面、主题与交互，创作能力通过 Skoob 官方 API 提供。

本仓库仅包含 React 网页、浏览器接口协议与公开静态资源。不包含服务端、数据库、桌面或手机客户端、核心引擎、平台提示词和平台管理端。断开官方服务后不能在本地执行核心能力。

## 开发与构建

Node.js 22 或更高版本：

```sh
npm ci
npm run dev
npm run build
npm run preview
```

默认连接 `https://skoob.cc`，不会启动或回退到本地引擎。端口被占用时退出，不结束其他程序。部署静态文件时需要把页面路由回退到 `index.html`。

复制 `.env.example` 为 `.env.local` 可指定 API 源地址；变量在构建时生效，需要重新构建。`VITE_*` 会公开给浏览器，禁止填写共享 API Key 或 OAuth client secret。

## 账号、费用与第三方域名

沿用官方 OAuth 登录与 sub2api 账号体系。保留自定义模型与服务商配置。选择官方中转站时，模型 Token 费用由 sub2api 计量和结算；选择自己的模型服务时，由用户与该服务商结算，Skoob 不另收这部分模型 Token 费用。网页不实现扣费。源码使用权限不包含免费 API、模型额度或托管服务权益。

本版采用官网当前的浏览器用户授权协议：用户登录后访问自己的数据。第三方部署域名必须由官方服务登记 CORS 与 OAuth 回跳地址；仅修改网页配置不能绕过这些校验。未经登记，页面可以加载，但登录和跨域请求可能被拒绝。

这是网页源码接入准备版，不宣称独立的第三方商户 API Key 接入已交付。将来以商户 Key 接入时，Key 必须保存在商户自己的服务端，不能嵌入本网页。公开 SDK、API 接口与使用限制见 [接入说明](docs/api-integration.md)。
