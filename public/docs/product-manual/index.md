# 焚诀 Skoob 产品手册

更新：2026-09-12。

## 小说 Agent，也是持续积累的知识库

焚诀面向小说作者，把灵感、拆书、世界仿真和分阶段写作连在一起。你可以从一句故事想法开始，也可以上传有权使用的小说材料，分析结构、人物动机、世界设定与伏笔，再把可访问的知识用于创作。

我们的核心要求是：**每一个生成或提取的设定，都应成为带档案的智能体。** 一本书留下的不只是正文，还有世界规则、实体关系、设定档案和可参考的创作方法。

知识库用于查找、理解和参考。产品要求是：私有作品不因建档而自动公开，跨用户使用必须有相应授权。当前派生资产权限与跨用户复用链路仍在上线前整改，不能将本手册当作这些要求已经全部验收通过的声明。

## 四大引擎

| 模块 | 在创作中做什么 | 典型用途 |
| --- | --- | --- |
| 天魔 | 寻找灵感，整理热点、素材与脑洞 | 选题、故事种子、书名简介参考 |
| 天王 | 拆解小说并积累知识，管理模板与风格 | 结构分析、设定检索、模板选择与策略路由 |
| 天衍 | 模拟世界中的智能体互动与事件变化 | 为大纲、卷与循环、正文提供推演素材 |
| 天工 | 提供 AI 生图、小说封面、AI 检测与改写等工具 | 为故事生成画面、制作封面、定位文字问题并打磨表达 |

天魔、天王、天衍、天工是四大引擎。天工聚合工具类能力，AI 检测只是其中一项；创作工作流负责把四大引擎组织起来。选择一个官方助手的人设，并不等于已经调用对应引擎；实际执行以任务记录与产物为准。

## 六步创作

| 步骤 | 你会做什么 | 主要结果 |
| --- | --- | --- |
| 1. 意图卡 | 明确题材、方向和篇幅目标 | 创作目标与约束 |
| 2. 世界观生成 | 确认世界规则、基础冲突与设定 | 世界观与基础实体 |
| 3. 书名与简介 | 按题材和模板挑选、调整故事钩子 | 候选书名与简介 |
| 4. 全书大纲 | 查看主线、卷结构和循环细节 | 分阶段生成的大纲与设定档案 |
| 5. 卷与循环 | 细化当前阶段目标、事件与节奏 | 卷与章节编排 |
| 6. 章节正文 | 根据已确认设定推进故事 | 正文、审核与结算结果 |

设定档案贯穿创作，人物卡不是单独的一步。步骤轨表示当前阶段；生成中的文字预览不能替代“本步已完成”的状态。

### 快速直出与世界仿真

**快速直出**保留创作编排、结构检查和保存流程，不调用天衍仿真。基础平台功能与模型用量是两件事，快速直出不意味着外部模型免费。

**仿真策略**在相应创作阶段加入天衍推演。智能体之间的行为与事件为创作提供素材，再由流程整理、检查并等待作者确认。轮数取决于阶段、配置和任务，不统一固定为 72 轮。

### 引导、剧场与互动影游

引导模式围绕工作台逐步确认；剧场模式通过对话观察、参与和调整故事；互动影游是独立的分支体验入口。全自动属于运行策略，减少逐步确认，不代表跳过校验。不同入口的功能范围以实际界面为准，小说与拆书模板不能默认视为已接入影游流程。

## 长大纲如何推进

长大纲先建立骨架，再按卷与循环分批补充细节和交接状态，并生成相应设定档案。已验证的批次保存为检查点；恢复任务时，系统可以复用仍有效的检查点，继续处理未完成部分。

修改上游世界观、模板或大纲结构可能使依赖内容需要重新检查或生成。网络故障、格式错误、实体冲突也需要不同处理；不断点击重试不能修复所有问题。

完整的结果需要同时满足正文结构、卷与循环细节、交接状态和设定档案要求。系统出现失败时应保留可检查的进度并提供恢复入口，但不承诺任何外部模型永远不中断。操作方法见 [失败与恢复](/site/docs/user-guide)。

## 每个设定都有档案

设定不只包括人物，还包括地点、势力、器物、能力、规则与体系。重要设定可以有详细档案，次要设定也应保留基本定义和来源。详略不影响是否建档。

档案应帮助回答：它是什么、从哪里来、有什么作用和限制、与谁有关、目前处于什么状态。非人物设定按其类型描述，不应为了套表格而虚构人的性格和成长经历。

你可以在作品工作台查看图谱档案，也可以在智能体入口浏览可访问的档案。**当前各生成、提取、同步路径的覆盖仍在完善**；看到一个目录或部分卡片，不能据此认为整本书所有设定已经验收齐全。

### 召唤与跨作品参考

可访问的设定智能体、专家团或模板可被选作创作参考。召唤应带上可用的档案和来源；上下文长度、资产就绪状态与权限会影响实际加载范围，不能理解成一次性读入所有图谱记忆。

复用的目的是参考知识。新书的名字、关系和世界规则以新书确认内容为准。暂时缺少档案、图谱或来源证据的资产，不应当被视为已经完整挂载；请结合使用回执和实际回答检查。

## 拆书与知识积累

从 [拆书入口](/deconstruction) 选择母本或上传材料，明确分析范围和材料来源。八师分工处理源文登记、结构测绘、开篇、实体、章节、脉络、设定与验收。

产物包括章节卡、节奏与情绪分析、逆向大纲、伏笔、设定和关系等，具体取决于选择的阶段及实际完成情况。知识库问答可帮助查找依据，模型的分析或推测仍应回到原文核实。

仅分析前几章的结果不能代表全书。任务受理、分析完成、档案就绪与可供他人引用是不同状态；共享与使用权限也需要单独确认。

## 模板、风格、Skill 与策略路由

模板规定某一步如何组织内容；写作风格描述叙述方式；Skill 提供可执行任务的方法与工具。这三种能力可以协作，但不是同一个东西。

- 同一步骤有多个模板，例如升级闯关型大纲、悬疑追索型大纲。
- 黄金一章、黄金三章拥有各自的模板槽，书名简介也可选择不同结构。模板应遵从现有设定，不能直接照搬示例书名、角色和剧情。
- 风格独立组合，例如自然具象、轻松吐槽、冷峻悬疑。
- 没有手动选择时，系统可按业务、步骤、题材与规则优先级选择模板，再使用执行智能体关联或默认配置。

在聊天框输入 `/`，可在技能、模板或风格分类中选择当前可用项。选择后形成真实的能力引用，单纯在文本里打一个名字并不代表已启用。

作品中的选择可保存；“仅本次使用”只绑定当前任务并用于该任务重试。更改管理配置不会自动改写已经确认的作品内容。

## 我的智能体与官方助手

“设置 → 我的智能体”用于管理你自己的助手身份与偏好。改名不应新建另一个身份，第一次聊天可以直接开始，之后再补充偏好。

官方助手角色提供不同的名字、头像、简介、欢迎语和交流风格；它们与作品中的设定智能体、负责执行任务的智能体分别管理。角色人设不授予额外账号权限，也不替代模型选择。

## 天工引擎：画面与文字的工具箱

天工提供 AI 生图、小说封面、AI 检测和文本改写等能力。封面编辑器支持上传或生成图片，用于作品的视觉呈现；检测与改写帮助定位和处理文字问题。不同工具使用对应的模型与配置。

独立封面入口与集中画风管理仍按当前迭代计划完善，具体操作以已开放入口为准。天工的产品定位不因此缩减为检测工具。

### 检测与改写的边界

天工由作者主动发起检测，提供文体、指纹及已配置模型评分等信号。查看报告时，需要结合文本覆盖、评分器可用性和校准状态理解结果。

分数不等于作者身份的证明，不保证与其他检测器同刻度，也不保证改写后通过其他平台检测。改写前后应核对原意、人物口吻、世界设定和情节事实。

## 账号、会员与平台配置

个人模型、个人路由、账号、我的智能体与会员状态在用户端设置中维护。功能能否使用以账号当前权益为准；目录能浏览不等于已获调用或下载权限。

平台级的天魔配置、天工打分模型、天王模板与路由、官方角色及权益映射由管理员在独立业务管理端维护。权限由 API 验证，普通用户不能通过直接访问管理地址获得管理权。

订单、支付和余额仍由中转站处理。官网与 [套餐页](/pricing) 展示供选购参考，成交价格、模型用量费用以结算页为准；支付完成后返回平台刷新并确认权益。
