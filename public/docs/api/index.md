# 焚诀开放平台

将小说领域能力接入你的应用。面向开发者、内容工作室与平台，按需购买天魔、天工、天衍、天王的引擎 API，用于选题工具、创作助手、内容检测和互动叙事。

> **开放状态：接入预告。** 首批七项能力的产品范围已确定，正式接口版本、费率与自助开通入口尚未发布。以下计量单位为产品设计口径，开放时以对应商品规格为准。

[查看接入指南](/site/docs/api-integration) · [了解创作者产品](/site/docs/product-manual)

## 选择你的 API 能力

| 引擎 | API 产品 | 你可以获得 | 拟定计量单位 |
| --- | --- | --- | --- |
| 天魔 | **扫榜** | 小说榜单分析，题材、卖点与趋势报告 | 每份完成的分析报告 |
| 天魔 | **脑洞** | 根据题材、素材与模板策略生成故事种子、候选书名和简介 | 每批完成的脑洞生成 |
| 天魔 | **热点** | 新闻与热点的结构化条目、摘要、来源及采集时间 | 查询请求；订阅另按更新额度 |
| 天工 | **AI 检测** | 文本检测信号、问题片段与覆盖信息 | 实际检测文本量 |
| 天衍 | **仿真模拟** | 世界与设定智能体的互动、事件推演和状态变化 | 已完成的仿真轮次及规格 |
| 天王 | **模板** | 大纲、书名简介、黄金一章、黄金三章等步骤模板，以及可组合的写作风格 | 授权调用次数及资产范围 |
| 天王 | **设定** | 可引用的结构化设定档案、关系、版本与来源信息 | 授权检索或引用次数 |

### 天魔：选题、生成与资讯分开调用

**扫榜**用于研究小说市场，**脑洞**用于生成创作方向，**热点**用于获取资讯素材。这是三个独立商品，不要求为了读热点而购买一次生成任务。脑洞使用的模板策略属于生成能力；天王模板是可单独接入的创作知识产品。

### 天工：把检测接进你的编辑流程

AI 检测可用于投稿初筛、编辑辅助和文本打磨。结果应结合文本覆盖与评分说明理解，不作为作者身份的证明。天工还包含生图、封面等工具；本批开放 API 范围先包含检测，其他工具以之后发布的目录为准。

### 天衍：让设定参与推演

向仿真引擎提供世界规则、设定和推演目标，获取互动事件与状态演化，用于剧情规划或互动叙事。长任务按任务管理，接入时需同时处理进度、结果和中断恢复。

### 天王：让知识可复用

同一步骤可以有多个模板，写作风格独立组合，按步骤、题材或显式选择匹配。设定档案覆盖人物、地点、势力、器物、能力、规则等；重要程度决定详略，每个设定都有档案信息。

购买的是指定范围内的模板或设定使用能力。资产需带有版本、来源和可用范围，不能因付费调用而获得其他用户的私有作品或未授权原文。

## API 怎样收费

API 是独立的付费产品线。创作者会员用于平台内功能；API 套餐用于你的应用调用引擎。购买创作者会员不自动获得 API 额度，模型服务余额也不自动获得引擎调用权限。

### 套餐结构

| 档位 | 面向谁 | 额度与结算方式 |
| --- | --- | --- |
| 试用 Free | 验证接入的开发者 | 开放后提供指定能力的有限测试额度，范围与有效期待发布 |
| Developer | 独立开发者、小团队 | 月度基础包；能力额度、并发和超额单价随商品发布 |
| Business | 工作室、业务平台 | 更高用量与并发；按能力组合配额，明确超额规则 |
| Enterprise | 大规模或定制集成 | 按需求报价；容量、服务支持与专属交付在合同中约定 |

**正式售价待发布。** 不把一次热点查询、一批脑洞生成和一轮仿真按相同成本折算；每项能力分别定义计量单位和费率。是否提供预付用量包、超额付费及组合优惠，以购买时的 API 商品为准。

### 一张报价单应写清什么

| 项目 | 购买前应确认 |
| --- | --- |
| 产品与规格 | 能力名称、接口版本、输入上限、每批产出或仿真规模 |
| 单位与单价 | 元/报告、元/批、元/查询，或每指定文本量、每轮的价格 |
| 包内额度 | 数量、有效期、适用能力，是否允许跨能力抵扣 |
| 超额规则 | 停止服务或按明确单价付费；预算上限与通知方式 |
| 异常结算 | 失败、取消、部分完成、幂等重试的计费规则 |
| 服务约定 | 并发、限流、支持范围，以及模型费用是否已包含 |

费用由购买的能力、实际结算数量及对应费率决定。示例：若某商品按“每千字”报价，100,000 字折算为 100 个计量单位；字符统计、分段去重与不足一个单位的取整方式必须由该商品说明，不能套用到其他能力。

## 从了解能力到完成接入

1. **选能力**：确认七项产品中哪些与你的业务相关。
2. **估用量**：列出月调用量、单次文本量、仿真规模及峰值并发。
3. **确认规格与报价**：核对可用接口版本、费率、额度和异常结算方式。
4. **获得开通资料**：取得服务域名、应用 API Key、授权范围和正式接口文档。
5. **测试后上线**：先验证成功、失败、限流与账单回执，再接入实际业务。

当前自助开通尚未开放，正式入口会在此页公布。现在可以先按 [接入指南](/site/docs/api-integration) 准备应用需求与服务端集成，不需要先购买创作者会员。

## 常见问题

**这是模型转发 API 吗？** 主要售卖小说领域的加工与推演能力：选题分析、脑洞、检测、仿真、模板和设定。模型只是实现这些能力的组成部分。

**天王模板和设定是一项产品吗？** 分开组织。模板提供创作方法与结构，设定提供可引用的档案与关系，可以组合使用。

**是否所有平台功能都会开放 API？** 本批范围就是上面的七项。其他工具和能力按之后的发布目录扩展。

**在哪里看具体参数和代码？** [接入指南](/site/docs/api-integration) 说明接入准备与调用方式。正式端点、请求响应 schema、错误码和示例将随可开通的接口版本发布。
