# 开发者接入指南

把焚诀引擎接入你自己的产品。先从 [能力与计费](/site/docs/api) 选择 API，再准备应用、用量与测试方案。

> **当前为接入准备文档。** 正式端点与自助开通尚未发布，本文不会将平台内部接口作为付费调用地址。以下流程与调用框架供接入准备，实际可用合同以开通资料为准。

## 服务域名与接口版本

规划服务域名为 **`https://skoob.cc`**。对外调用使用 HTTPS 域名，不需要了解平台内部部署端口。

正式开通资料会给出完整 **Base URL、版本前缀和端点路径**，以及对应的请求、响应与错误码。域名规划不表示当前已有可购买调用的生产端点；接入时复制开通资料中的完整地址，不从创作网页地址推测接口路径。

## 开通前准备这些信息

| 信息 | 示例 |
| --- | --- |
| 应用场景 | 在编辑器中检测提交的章节 |
| 需要的能力 | 天工 AI 检测；或天魔热点 + 脑洞 |
| 输入与产出 | 每篇约 3,000 字，需要报告和问题片段 |
| 月用量与并发 | 预计每月 2,000 篇，峰值同时 5 个任务 |
| 数据范围 | 自有文本；需要引用的模板或设定范围 |
| 预算与运行方式 | 月预算、超额是否停用、结果允许等待多久 |

当前没有自助申请或购买入口。开放时会在 [开放平台](/site/docs/api) 公布，不要用创作者会员订单代替 API 开通。

## 开通时应获得什么

- 应用身份与 API Key，明确可调用的能力和数据范围。
- 正式服务地址、版本化端点、字段说明及可运行示例。
- 价格、配额、输入限制、并发与限流规则。
- 请求或任务标识、状态查询方式、异常处理及结算规则。
- 用量查询、账单核对、密钥撤销或轮换、技术支持入口。

拿到这些资料后再进入联调。API Key 属于你的服务端凭据；用户登录态、创作者会员和 API 调用身份分别使用。

## 从你的服务端调用

建议调用链为：**你的客户端 → 你的业务服务 → 焚诀开放 API → 返回结果**。API Key 放在服务端密钥配置中，不写入网页、移动端安装包或公开仓库。

鉴权采用 Bearer API Key 的接入方向：

```http
Authorization: Bearer <开通的应用APIKey>
Content-Type: application/json
```

下面是 **JSON POST 的接入骨架，不是当前可执行的接口示例**。`SKOOB_API_ENDPOINT` 必须替换为开通资料中的完整 HTTPS URL，`request.json` 必须符合该版本的请求 schema；查询类接口使用其规定的方法和参数。

```bash
# 在你的服务端运行环境中设置这两个变量：
# SKOOB_API_ENDPOINT：开通资料中的完整端点地址
# SKOOB_API_KEY：该应用的 API Key
curl --fail-with-body "$SKOOB_API_ENDPOINT" \
  --header "Authorization: Bearer $SKOOB_API_KEY" \
  --header "Content-Type: application/json" \
  --data-binary @request.json
```

正式示例会按能力分别提供，不要求所有 API 共享同一个请求体。不要把密钥放进 URL 查询参数。

## 长任务、失败与重试

脑洞批次、检测大文本和多轮仿真可能需要任务式处理。以正式接口说明为准，区分“已受理”和“已完成”：拿到任务标识后查询已有任务，不因等待时间较长就反复创建新任务。

- **网络中断或服务暂时不可用**：先确认请求是否已被受理；只有接口明确支持幂等时，才使用同一幂等标识重试创建。
- **限流**：按接口给出的等待时间和重试规则处理，控制并发。
- **参数、密钥、权限或额度问题**：修正原因后再调用，避免无效重试。
- **部分完成或取消**：区分可用产物与未完成部分；按商品约定核对结算，不能推断必定全免或全额收费。

已完成的任务应保存结果标识及版本，方便后续复用与核对。具体轮询间隔、有效期、幂等窗口与恢复方法随接口版本发布。

## 联调与费用核对

上线前，用获批的测试额度完成一次小规模调用，验证输入、输出、任务状态和页面展示。再验证错误参数、无效密钥、权限不足、限流和中断后的处理方式。

每次调用保留接口版本、请求或任务标识、时间、状态与结算回执，避免记录密钥和不必要的原文。核对“已完成数量、计量单位、对应单价”与商品规则一致，确认超额策略后再放大调用量。

遇到问题时，向开通资料中的支持渠道提供上述标识和脱敏错误信息。正式 SDK、错误码表、服务状态页和在线调试入口会在能力开放时一并说明，当前不提供未发布的安装命令或入口。
