# 焚诀 Skoob 用户指南

更新：2026-09-12。本指南以当前小说创作界面为准；账号权益、资产是否就绪及模型可用性以实际回执为准。

## 第一次使用

打开 [创作](/create)，按页面引导登录。在“设置 → 模型”检查当前可用模型与凭据，发送任务前确认模型选择。

第一次聊天不要求先填写完整人设。你可以直接描述想写的故事，也可以先到 [我的智能体](/settings/agent) 设置名字、简介与偏好，之后再调整。官方角色的名字与头像用于交流体验，实际模型和能力仍由当前任务配置决定。

例如：

> 我想写一本都市悬疑小说。主角在失物招领处工作，每周都会收到一件来自未来的物品。先帮我整理意图卡，指出规则中可能矛盾的地方。

也可以上传你有权使用的小说材料，要求分析具体章节。等待附件解析完成；上传成功不代表 Agent 已读完全文。

## 从意图卡开始创作

在创作页选择引导模式，填写或讨论故事方向，再选择快速直出或仿真策略。

- **快速直出**使用创作编排完成各步，不进行天衍仿真。模型调用费用按所用服务规则结算。
- **仿真策略**在相应阶段加入世界模拟，需要当前账号具备对应权益。
- **剧场模式**适合通过对话参与和调整故事。
- **互动影游**使用独立流程；不要假设小说模板会自动作用于影游。

全自动在工作台作为运行方式设置，不能绕过生成校验。刚建立世界观时，逐步审阅更方便发现偏差。

## 审阅六个阶段

| 阶段 | 建议重点检查 |
| --- | --- |
| 意图卡 | 题材、受众、篇幅、核心冲突与不能改变的约束 |
| 世界观生成 | 能力限制、世界规则、基础设定是否矛盾 |
| 书名与简介 | 钩子是否来自当前设定，是否暴露过多后续情节 |
| 全书大纲 | 主线与卷目标、循环顺序、状态交接、伏笔和档案覆盖 |
| 卷与循环 | 当前事件是否承接上阶段结局，节奏与章节目标是否清楚 |
| 章节正文 | 人物行为、器物状态、地理关系和规则是否保持一致 |

在工作台查看当前阶段产物和任务状态，按实际按钮确认、反馈或重做。对话中修改上游要求可能使下游产物失效；“页面上还有旧文字”不等于新版仍然有效。

生成正文时，以目标作品的已确认设定为依据。需要引入新的器物、能力或规则时，应明确其定义、来源和限制，并检查是否已进入档案。

## 选择模板、写作风格与 Skill

在聊天输入框输入 `/`，切换技能、模板或写作风格分类，选择可用项。可选目录会随管理配置与权限变化。

例如创作悬疑故事时，选择适用于全书大纲的悬疑模板，再组合冷峻悬疑风格。模板负责结构，风格负责表达，Skill 负责执行方法；同一步骤不要同时选择互相冲突的两套模板。

- 默认选择可保存到当前作品的对应步骤；风格用于当前作品的写作表达。
- “仅本次使用”绑定这次任务，重试时继续沿用，其他任务不继承。
- 无作品的普通聊天仅对本次有效。
- 管理员新增或修改模板不会自动重写你已经确认的产物。
- 如提示模板停用或不存在，重新选择有效项；不要只把旧模板名写进消息后当作已启用。

黄金一章模板用于第一章，黄金三章用于前三章，并可参与开篇规划。它们是不同的模板类别，可以各自有多个方案。

## 查看设定档案

在当前作品工作台打开“图谱档案”，查看实体与关系。也可从 [智能体](/agents) 入口查看可访问的档案。

所有设定都应建档：人物、地点、势力、器物、规则、能力等，不能因为次要或不是人物而省略。简单档案说明它是什么、有何作用、来自哪里；详细档案再补充限制、状态、关系和演变。

查看时尤其留意：

- 同一个设定是否使用一致的名字，别名是否说明清楚。
- 器物、规则等是否被错误写成人物。
- 新增设定是否只有正文提及，却缺少档案。
- 图谱是否反映当前作品版本，列表是否只加载部分结果。

若缺少档案，请在当前任务里指出原名、出现位置与已有定义。不要通过删除设定、随便换名或跳过校验来继续生成。部分卡片可见不代表整本档案已经完整验收。

## 召唤已有知识作为参考

在可访问的模板或智能体目录选择适用资产，使用界面提供的“使用/召唤”入口，或在对话中选用相应能力。

可以这样描述用途：

> 参考这份设定档案的“能力需要付出代价”的设计方法，不沿用原书人物、地点和专有名词。先列出与我当前世界观冲突的地方。

查看实际使用结果：资产是否就绪、档案是否加载、引用是否有来源、是否仍受权限限制。只出现一个书名或头像，不等于整份知识库已进入上下文。

跨作品引用应服从目标作品的规则；跨用户引用需要资产的公开/共享状态和使用权限。不要把私有原文当作默认公共素材。目前派生资产权限、档案与来源覆盖仍在上线前整改，尚不能把完整跨用户共享链路视为已验收功能。

## 拆书与知识库问答

从 [拆书](/deconstruction) 进入，选择母本或上传有权处理的材料，确认题材、分析阶段和覆盖范围。

拆书任务逐阶段提炼章节、开篇、实体、事件脉络、设定与验收信息。运行中可以查看进度与产物；暂停/恢复在执行边界生效，当前批次可能先完成。

完成后可围绕结构和证据提问，例如“主角第一次改变目标在哪一章？”或“这条规则在哪些场景被验证？”。核对引用的章节与原文，不把模型推测直接当成源文事实。

前几章分析不等于全书分析。分享或复用前确认覆盖范围、来源版本、图谱与档案是否实际就绪。

## 天工引擎的创作工具

天工覆盖 AI 生图、小说封面、AI 检测与文本改写。作品详情中的封面编辑器支持上传或生成图片；生成前确认生图模型与画面要求，成功后检查作品封面的保存结果。独立封面入口与风格配置以当前版本实际开放情况为准。

### AI 检测与改写

打开 [天工 AI 检测](/deai)，按界面要求提交文本并选择当前可用能力。

先查看覆盖范围、问题位置与检测信号，再判断是否需要改写。评分器未配置、不可用或未充分校准时，不能把结果当作完整的模型检测结论。

改写后对照原文检查情节事实和角色口吻。检测只能辅助修改，不能证明文章由人或 AI 创作，也不承诺通过其他平台检测。

## 失败与恢复

长大纲分批生成，最后还可能继续生成交接状态与设定档案。先看当前阶段和完成状态，不要只凭文字已经出现就判断整份大纲完成。

| 现象 | 建议处理 |
| --- | --- |
| 页面未更新 | 使用“重新读取”获取持久状态，确认后台是否仍在运行，避免重复发起整本任务 |
| 暂时性网络错误 | 等待当前重试策略执行；耗尽后检查模型连接与服务状态，再恢复当前任务 |
| 结构或字段校验失败 | 保留错误字段与批次编号，针对失败批次修复；增加网络重试不能解决数据结构问题 |
| 交接状态出现未知实体 | 对照完整设定档案与世界观核实原名、类别和来源，避免仅按核心人物列表判断 |
| 任务已暂停 | 使用当前页面的继续/恢复操作，以后续状态确认推进 |
| 部分结果可见但本步失败 | 已验证批次可以复用，失败候选仍需修复；不要将候选误判成可用于下一步的完整结果 |

当前暂时性请求错误最多额外重试 5 次，基础间隔为 2、4、8、16、32 秒。权限错误、缺失档案和结构问题需要相应修复，不会因为多等一会儿自行变正确。

反馈故障时提供作品名、当前步骤、失败批次、尝试次数与错误时间；保留已确认内容，不反复重做上游。模型服务和本地链路都有可能导致失败，不能仅凭“无法连接 API”的概括提示认定供应商不稳定。

## 账号、会员与平台管理

[个人设置](/settings/account)管理本人账号；[模型](/settings/models)、[路由](/settings/routing)、[我的智能体](/settings/agent)分别管理个人使用偏好。查看 [会员权益](/settings/membership) 确认当前账号允许哪些操作。

平台管理是独立入口，仅平台管理员可用；其中管理天魔采集与提示词、天工评分器、天王多模板与路由、官方助手和权益映射。普通用户的个人配置不会替代这些全平台设置。

购买通过 [套餐页](/pricing) 跳转中转站结算。官网价格为展示信息，成交价格及模型用量费用以结算页为准。购买后返回平台刷新状态；若权益未到账，先检查订单和当前登录账号。
